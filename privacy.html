MKADP 公式ドキュメント

プライバシーポリシー

最終更新日: 2026年11月27日

MK All Database Program（以下「本サービス」といいます）は、利用者のプライバシーを尊重し、本サービス上で扱われるデータの取り扱い方針を以下のとおり定めます。

1. 端末内に保存されるデータ

本サービスでは、戦績データ・コース別集計・言語設定・ユーザー設定などを利用者のブラウザ内ストレージ（localStorage および IndexedDB）に保存します。これらのデータは原則として利用者自身の端末内に保持され、開発者が自動的に閲覧・収集することはありません。

2. 外部送信・連携機能におけるデータの扱い

本サービスの一部機能では、利用者の操作または設定に基づき、以下の外部通信が発生する場合があります。

  • Discord Webhook 送信機能：利用者が自ら入力した Webhook URL 宛に、戦績レポートや統計画像・テキストを送信します。
  • 統計データ・バックアップ同期機能（有効化時）：利用者が統計集計・バックアップ同期機能を利用する場合、対戦結果・識別用ID・タイムスタンプ等のデータが連携先サーバーへ送信されます。
  • 外部API・プレイヤー情報取得機能：利用者がプレイヤーIDや検索名を指定した場合、公開されているラウンジ／対戦統計APIから情報を取得するためにリクエストを行います。
  • OBS WebSocket 連携（ローカル版）：利用者が指定したローカルネットワーク上の OBS WebSocket に対して表示用データを送信します。

3. Discord Activity として起動した場合の情報

本サービスを Discord Activity（埋め込みアプリ）として起動した場合、Discord Embedded App SDK を通じてセッションの接続状態やチャンネル／サーバー識別情報等がメモリ上で参照されることがありますが、本サービスの機能提供以外の目的で利用・販売・第三者提供することはありません。

4. 第三者提供の制限

開発者は、法令に基づく場合や利用者が自ら指定した外部連携先（Discord Webhook 等）への送信を除き、利用者のデータを第三者に提供しません。

5. データの削除・管理

端末内に保存された戦績データや設定は、本サービス内の削除・リセット機能、またはブラウザのサイトデータ消去機能からいつでも削除できます。

6. ポリシーの変更

本プライバシーポリシーの内容は、機能追加や法令・プラットフォーム規約の変更に応じて改定されることがあります。改定後の内容は本ページに掲載した時点から効力を生じます。
