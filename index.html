配布・分析ツール

MK All Database Program

MKWorld及びMK8DXラウンジでの対戦データやスコアを簡単に可視化・分析するためのWebブラウザ対応ツールです。

🌐 ツールを直接開く(MKワールド版) 📥 ファイルをダウンロード (.html)
🌐 ツールを直接開く(MK8DX版) 📥 ファイルをダウンロード (.html)
📥 オーバーレイファイルをダウンロード (.html)

📊 各機能の解説と使い方

1. レースグラフ＆傾向分析

  • コースごとの得意・不得意の分析データ出力
  • 安定度や平均順位などのスタッツ分析
  • 様々な表やランキングで客観的なスタッツ分析が可能！

2. 分析結果の出力・共有

  • ローカル環境でのファイル保存に対応!
  • webhookURLを使いコースごとの分析データをDiscordに送信共有可能!
  • さらにwebhookURLがあればラウンジstatsも表示&送信可能!

3. 配信者用オーバーレイ搭載!

  • obsのWebSoket機能を使い配信画面に分析データを表示可能!(ローカルファイル版のみ可能)

🚀 ツールのご利用手順

1 ツールを起動する

「ツールを直接開く」ボタンをクリックするか、ダウンロードした MKADP.html ファイルをブラウザ（Chrome, Edge, Safari等）で開きます。

2 順位データを入力する

レース登録フォームにラウンジや大会や野良の各レース順位等情報を入力し、「保存」ボタンを押します。

3 グラフと分析結果を確認する

自動生成された分析データ、推移グラフを確認して戦況を振り返ります。

4 結果をコピー・保存する

Discord等に共有するか、分析データを保存します。
